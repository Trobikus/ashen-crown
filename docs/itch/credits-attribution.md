## Warum das zählt

CC BY 3.0 verlangt die Namensnennung der Urheber und die Lizenzangabe an
jeder Stelle, an der das Werk erscheint — bei einem Spiel gehört das auf die
Storeseite. Der Link auf game-icons.net hilft zusätzlich Neugierigen, ist
aber kein Lizenzersatz.
